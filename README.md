CCNA 200-301 routing objectives.

## Tools Used
- GNS3 for simulation
- Wireshark for packet capture
## How to Use
1. Import topology from `diagrams/` into GNS3
2. Apply configs from `configs/` to each device
3. Follow the lab guide in `labs/`
